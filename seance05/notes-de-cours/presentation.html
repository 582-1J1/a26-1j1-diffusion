Instructions conditionnelles

Les conditions permettent au programme d'appliquer les règles du jeu selon son état.

01 · if

Exécuter une action si une condition est vraie

if (score >= objectif) {

console.log("Objectif atteint !");

}

02 · else

Prévoir le cas contraire

if (nombreVies > 0) {

console.log("La partie continue.");

} else {

console.log("La partie est terminée.");

}

03 · else if

Vérifier plusieurs possibilités

if (score >= 5) { ... }

else if (score >= 3) { ... }

else { ... }

Les tests sont faits de haut en bas. La première condition vraie est retenue.

04 · Comparer

Les comparaisons produisent vrai ou faux

  • === égal à
  • !== différent de
  • >, <, >=, <=

Le résultat d'une comparaison est une valeur booléenne : true ou false.

05 · Logique

Combiner plusieurs règles

  • && : et, toutes les conditions doivent être vraies
  • || : ou, au moins une condition doit être vraie
  • ! : non, inverse une valeur booléenne
06 · Projet fil-rouge

Ouvrir la porte du jardin

if (lucioleRecueillie && score >= objectif) {

console.log("La porte est ouverte.");

}

Cette règle pourra être reliée à la collision avec une luciole dans le Canvas.

07 · Travail de classe

La porte du jardin

  • Créer trois états pour la porte.
  • Combiner la collecte et le score avec &&.
  • Vérifier les vies restantes avec une deuxième condition.
