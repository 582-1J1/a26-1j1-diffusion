582-1J1 · Séance 2

Découvrir l'environnement de développement

Avant de programmer un jeu, il faut savoir où écrire le code, comment organiser les fichiers et comment observer le résultat.

01 · Les outils

Deux outils, deux rôles

  • Visual Studio Code sert à écrire et à organiser le code.
  • Le navigateur Web ouvre la page et exécute le JavaScript.
  • Les outils de développement aident à observer et à déboguer.
02 · Le projet

Une arborescence claire

mon-projet/

├── index.html

└── assets/js/script.js

Le navigateur part de index.html et suit les chemins relatifs pour charger les autres fichiers.

03 · Le lien

HTML charge JavaScript

<script src="assets/js/script.js"></script>

Cette balise indique au navigateur où se trouve le fichier JavaScript.

04 · Observer

La console montre ce que fait le programme

console.log("Le fichier JavaScript est chargé.");

La console est un espace de travail réservé à l'observation du programme. Elle n'est pas affichée dans la page du joueur.

05 · Déboguer

Quand quelque chose ne fonctionne pas

  1. Vérifier le chemin du fichier JavaScript.
  2. Vérifier le nom exact des fichiers et des dossiers.
  3. Lire le message dans la console.
  4. Enregistrer les fichiers et recharger la page.
06 · Atelier

À vous de jouer

  • Installer Visual Studio Code et les extensions présentées.
  • Reproduire l'arborescence du gabarit.
  • Modifier un message dans script.js.
  • Observer le nouveau message dans la console.
