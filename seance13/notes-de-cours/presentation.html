Tableaux, fonctions et événements de la souris

Construire l'écran de titre du jardin des lucioles.

01 · Tableaux

Une liste de valeurs

const couleurs = ["jaune", "vert", "bleu"];

console.log(couleurs[0]); // "jaune"

console.log(couleurs.length); // 3

Le premier index est 0.

02 · Tableaux

Modifier et parcourir

couleurs.push("rouge");

let index = 0;

while (index < couleurs.length) {

console.log(couleurs[index]);

index++;

}

03 · Fonctions

Pourquoi des fonctions?

  • Éviter de répéter le même code.
  • Donner un nom à une intention.
  • Diviser un programme en petites tâches.
  • Corriger à un seul endroit.
04 · Déclaration

Écrire la recette

function saluerJoueur() {

console.log("Bienvenue !");

}

Déclarer une fonction ne l'exécute pas.

05 · Appel

Suivre la recette

saluerJoueur();

saluerJoueur();

Chaque appel exécute le corps de la fonction. Ici, le message s'affiche deux fois.

06 · Déclaration ou appel?

Ne pas confondre

  • function saluerJoueur() { ... } : déclaration, une seule fois.
  • saluerJoueur(); : appel, autant de fois que nécessaire.
  • saluerJoueur sans parenthèses : on désigne la fonction, on ne l'exécute pas.
07 · Ordre d'exécution

Le programme saute dans la fonction

console.log("2. Avant l'appel");

annoncerPartie(); // saute dans la fonction

console.log("4. Après l'appel");

Après l'appel, l'exécution reprend à la ligne suivante.

08 · Paramètre et argument

La case et ce qu'on écrit dedans

function saluerJoueur(nomJoueur) {

console.log("Bienvenue, " + nomJoueur);

}

saluerJoueur("Alex");

nomJoueur est un paramètre (déclaration). "Alex" est un argument (appel).

09 · Plusieurs paramètres

L'ordre compte

function afficherPosition(nom, x, y) { ... }

afficherPosition("Luciole", 120, 80);

Les arguments sont associés aux paramètres selon leur position.

10 · Valeur de retour

return renvoie un résultat

function additionner(a, b) {

return a + b;

}

const total = additionner(5, 3); // 8

L'appel est remplacé par la valeur retournée.

11 · Afficher ou retourner?

console.log n'est pas return

  • console.log() affiche pour le programmeur.
  • return renvoie une valeur au reste du programme.
  • Sans return, une fonction renvoie undefined.
  • return termine la fonction.
12 · Nomenclature et portée

Nommer et limiter

  • Verbe d'action en camelCase : dessinerScene.
  • Un commentaire documente la fonction.
  • Variable globale : accessible partout.
  • Variable locale : n'existe que dans la fonction.
13 · Événements

Réagir au joueur

canvas.addEventListener("click", gererClic);

L'élément surveillé, le nom de l'événement, et le nom de la fonction à déclencher.

14 · Sans parenthèses

Le navigateur appelle la fonction

addEventListener("click", gererClic); // correct

addEventListener("click", gererClic()); // erreur

Avec des parenthèses, la fonction est appelée tout de suite, avant tout clic.

15 · Souris

click et dblclick

function gererClic(evenement) {

console.log(evenement.offsetX, evenement.offsetY);

}

L'objet de l'événement contient la position du curseur dans le Canvas.

16 · Zone cliquable

Le curseur est-il sur le bouton?

function estDansRectangle(pointX, pointY, rectX, rectY, largeur, hauteur) {

return pointX >= rectX && pointX <= rectX + largeur &&

pointY >= rectY && pointY <= rectY + hauteur;

}

17 · États du jeu

intro, jeu, résultat

let etatJeu = "intro";

function boucleJeu() {

if (etatJeu === "intro") { dessinerIntro(); }

else if (etatJeu === "jeu") { dessinerJeu(); }

else if (etatJeu === "resultat") { dessinerResultat(); }

}

Pour l'instant, c'est nous qui appelons boucleJeu(). Bientôt, elle sera appelée automatiquement.
