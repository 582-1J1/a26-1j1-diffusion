Manipulation de nombres et de valeurs booléennes

Un jeu utilise des calculs, des conversions et des règles pour décider ce qui doit se passer.

01 · Opérateurs arithmétiques

Calculer avec des nombres

score = score + 2;

let reste = score % 2;

  • + - * / : les quatre opérations de base
  • % : le reste d'une division
02 · Incrémentation

Augmenter ou diminuer une valeur

score++;

nombreVies--;

++ ajoute 1, -- soustrait 1.

03 · Conversion

Une chaîne de caractères n'est pas un nombre

let reponse = prompt("Combien ?");

let n = Number(reponse);

prompt() retourne toujours une chaîne. Number() la convertit.

04 · Débogage

Alert, prompt et typeof

  • alert() affiche un message.
  • prompt() pose une question.
  • typeof indique le type d'une valeur.
  • Consultez une référence fiable, comme MDN, en cas de doute.
05 · Comparaisons

Une comparaison produit vrai ou faux

const objectifAtteint = score >= objectif;

Le résultat est une valeur booléenne : true ou false.

06 · Opérateurs

Comment comparer deux valeurs

  • === : égal à
  • !== : différent de
  • > et < : plus grand ou plus petit
  • >= et <= : inclut l'égalité
07 · Aperçu

Un premier regard sur if et else

if (score >= objectif) {

console.log("Objectif atteint !");

} else {

console.log("Continuez !");

}

Nous approfondirons les conditions au prochain cours.

08 · Pour le projet

Les règles du jardin

  • Augmenter le score avec ++.
  • Convertir une réponse en nombre.
  • Comparer le score à un objectif.

Ces opérations feront plus tard partie des règles de nos projets de jeux.

09 · Travail de classe

Signaux dans le jardin

  • Utiliser les opérateurs arithmétiques et l'incrémentation.
  • Convertir une réponse avec Number().
  • Écrire une condition avec if et else.
