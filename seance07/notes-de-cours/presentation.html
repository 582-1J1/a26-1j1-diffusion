Construire une scène avec le Canvas

Nous reprenons les bases du Canvas et approfondissons le chargement et l'affichage des images.

01 · Rappel

Récupérer le Canvas et son contexte

const canvas = document.querySelector("canvas");

const contexte = canvas.getContext("2d");

Le contexte 2D fournit les méthodes de dessin.

02 · Rappel

Afficher du texte avec fillText()

contexte.font = "28px sans-serif";

contexte.fillText("Trouvez la luciole !", 30, 45);

03 · Image

Créer une image avec Image()

const imageLuciole = new Image();

imageLuciole.src = "assets/images/luciole.svg";

Le chemin est relatif au fichier index.html.

04 · Chargement

Attendre avant de dessiner

function imageLucioleChargee() {

dessinerScene();

}

imageLuciole.addEventListener("load", imageLucioleChargee);

Le dessin commence lorsque la ressource est prête.

05 · Couches

Dessiner dans un ordre précis

  • arrière-plan;
  • message et décor;
  • joueur;
  • objets importants.

Chaque nouveau dessin apparaît par-dessus les précédents.

06 · Taille

Redimensionner avec drawImage()

contexte.drawImage(imageLuciole, 600, 180, 40, 40);

Les deux derniers paramètres indiquent la largeur et la hauteur de l'image dessinée.

07 · Redessin

Effacer avant de redessiner

contexte.clearRect(0, 0, canvas.width, canvas.height);

Cette étape prépare les futures scènes animées.

08 · Projet fil-rouge

Composer la scène du jardin

  • un fond;
  • un message;
  • un joueur;
  • une luciole chargée comme image.

La scène reste statique. Le déplacement viendra plus tard.

09 · Travail de classe

Composer la scène du jardin

  • Charger deux images.
  • Attendre leur chargement.
  • Organiser les couches.
  • Redimensionner un élément.
