# Séance 7 : Construire une scène avec le Canvas

### Objectifs
- Revoir la récupération du Canvas et du contexte 2D
- Revoir l'affichage de texte avec `fillText()`
- Charger une ou plusieurs images avec `Image()`
- Attendre le chargement des images avant de les dessiner
- Organiser les éléments selon un ordre de dessin
- Redimensionner une image avec `drawImage()`
- Effacer et redessiner la surface du Canvas
