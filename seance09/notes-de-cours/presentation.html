Boucles, tableaux, hasard et pseudo-code

Donner une population de lucioles au Jardin des lucioles.

01 · while

Répéter tant qu'une condition est vraie

let compteur = 0;

while (compteur < 3) {

compteur++;

}

La condition doit pouvoir devenir fausse.

02 · Tableaux

Rassembler plusieurs valeurs

const positionsX = [];

positionsX.push(120);

console.log(positionsX[0]);

Les index d'un tableau commencent à zéro.

03 · hasard

Produire une position différente

const positionX = Math.floor(Math.random() * 760);

Math.random() produit une valeur aléatoire. Math.floor() donne un entier.

04 · Lucioles

Créer une population limitée

const MAX_LUCIOLES = 12;

while (indexLuciole < MAX_LUCIOLES) {

positionsX.push(positionX);

positionsY.push(positionY);

indexLuciole++;

}

05 · Analyse

Comprendre le problème avant le code

  • Quelles données faut-il conserver ?
  • Quelle règle limite le nombre de lucioles ?
  • Quelles positions sont visibles ?
  • Dans quel ordre dessiner les éléments ?
