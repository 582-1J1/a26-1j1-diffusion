# Le champ de lucioles

## Objectif

Analyser une petite règle de jeu, rédiger son pseudo-code, puis générer plusieurs lucioles à des positions aléatoires avec une boucle `while` et des tableaux simples.

## Préparation

1. Ouvrez le dossier [jardin-lucioles](../jardin-lucioles/).
2. Ouvrez `index.html` dans votre navigateur.
3. Observez le fond de forêt et les lucioles générées.

## Consignes

1. Modifiez la constante `MAX_LUCIOLES` pour obtenir un autre niveau de difficulté.
2. Ajoutez une constante `MARGE_LUCIOLE` pour éviter que les lucioles soient dessinées trop près du bord.
3. Ajustez les calculs aléatoires des positions `x` et `y` pour utiliser cette marge.
4. Ajoutez un message dans le Canvas qui indique le nombre de lucioles créées.
5. Rédigez d'abord votre pseudo-code dans un fichier temporaire ou dans vos notes.
6. Vérifiez que vos deux boucles `while` ont une condition qui peut devenir fausse.

## Vérification

Avant de montrer votre travail :

- les lucioles sont conservées dans des tableaux simples;
- les positions changent lorsque la page est rechargée;
- le nombre de lucioles ne dépasse pas `MAX_LUCIOLES`;
- les lucioles restent dans la zone visible;
- seules des boucles `while` sont utilisées;
- le pseudo-code décrit les étapes dans le bon ordre;
- la console ne contient aucune erreur.
