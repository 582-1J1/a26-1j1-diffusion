# Séance 19 : Fonctions temporelles, objets et interactions

### Objectifs
- Différencier `setTimeout()` et `setInterval()`
- Expliquer le rôle d'une boucle de jeu ou d'animation
- Regrouper les données d'une entité dans un objet
- Lire et modifier les propriétés d'un objet avec la notation pointée ou les crochets
- Réagir aux événements du clavier `keydown` et `keyup`
- Détecter la touche concernée avec `event.key`
- Utiliser l'objet `Audio` pour produire une rétroaction sonore
- Combiner des rétroactions visuelles et sonores dans un jeu
