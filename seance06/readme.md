# Séance 6 : Introduction à la surface de dessin du navigateur

### Objectifs
- Récupérer une balise `<canvas>` dans une page Web
- Obtenir un contexte de dessin en deux dimensions
- Afficher du texte avec `fillText()`
- Charger une image avec l'objet `Image()`
- Afficher une image avec `drawImage()`
- Effacer la surface de dessin avec `clearRect()`
