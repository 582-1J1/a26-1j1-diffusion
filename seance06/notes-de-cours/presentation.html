Introduction à la surface de dessin du navigateur

Le Canvas permet de construire la première scène visuelle du Jardin des lucioles.

01 · Canvas

Une surface de dessin dans la page

<canvas width="800" height="500"></canvas>

Le Canvas réserve une surface. JavaScript doit ensuite dessiner son contenu.

02 · Contexte

Obtenir le contexte 2D

const canvas = document.querySelector("canvas");

const contexte = canvas.getContext("2d");

Le contexte donne accès aux méthodes de dessin.

03 · Texte

Afficher un message avec fillText()

contexte.fillStyle = "#f6bd60";

contexte.font = "28px sans-serif";

contexte.fillText("Trouvez la luciole !", 30, 45);

04 · Image

Charger une image avec Image()

const imageLuciole = new Image();

imageLuciole.src = "assets/images/luciole.svg";

Le chemin de l'image est relatif au fichier index.html.

05 · Affichage

Dessiner l'image avec drawImage()

imageLuciole.addEventListener("load", () => {

contexte.drawImage(imageLuciole, 600, 180, 40, 40);

});

On dessine l'image après son chargement.

06 · Effacer

Effacer la surface avec clearRect()

contexte.clearRect(0, 0, canvas.width, canvas.height);

Cette étape sera essentielle lorsque la scène sera redessinée.

07 · Projet fil-rouge

La première scène du jardin

  • un fond;
  • un message;
  • un joueur;
  • une luciole.

La scène est statique pour l'instant. Le déplacement et l'interaction viendront plus tard.

08 · Travail de classe

La scène du jardin

  • Modifier le message.
  • Déplacer les éléments.
  • Ajouter une forme.
  • Organiser le redessin dans une fonction.
