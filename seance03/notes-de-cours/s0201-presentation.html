Introduction au langage JavaScript

Un programme conserve des informations, les transforme et les utilise pour faire fonctionner un jeu.

01 · Variables

Une variable conserve une information

let message = "La partie commence.";

message = "Trouvez les lucioles.";

Avec let, la valeur peut être remplacée pendant l'exécution.

02 · Constantes

Une constante ne change pas

const titreJeu = "Le jardin des lucioles";

Le titre du jeu reste le même pendant la partie. const décrit donc bien cette information.

03 · Affectation

Le signe égal affecte une valeur

message = "Trouvez les lucioles.";

La valeur située à droite est placée dans la variable située à gauche.

04 · Expressions

Une expression produit une valeur

const message = "Bienvenue dans " + titreJeu;

Le signe + permet de réunir deux chaînes de caractères.

05 · Chaînes

Manipuler des textes

const nom = "Lucioles";

nom.toUpperCase();

nom.length;

Une chaîne est un texte entre guillemets. JavaScript peut en lire la longueur ou modifier sa casse.

06 · undefined

Une information peut être absente

let score;

console.log(score); // undefined

La variable existe, mais aucune valeur ne lui a encore été attribuée.

07 · Pour le jeu

Préparer les informations du projet

  • le titre du jeu;
  • le nom du joueur;
  • un message;
  • le score.

Ces informations pourront être utilisées plus tard dans le Canvas.
