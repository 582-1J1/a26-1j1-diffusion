582-1J1 · Séance 10

Produire un algorithme en pseudo-code

Analyser un problème, le décrire en pseudo-code, puis le traduire en JavaScript.

01 · Étapes

Avant de programmer

  • Analyser le problème.
  • Rechercher une solution.
  • Rédiger un pseudo-code.
  • Valider le pseudo-code.
  • Programmer la solution.
02 · Analyse

Comprendre avant d'écrire du code

  • Quel est le résultat attendu ?
  • Quelles données sont déjà connues ?
  • Quelles règles doivent être respectées ?
  • Quels cas limites existent ?
03 · Pseudo-code

Les mots-clés de cette séance

  • INITIALISER, AFFECTER
  • SI ... ALORS ... SINON ... FIN SI
  • TANT QUE ... FAIRE ... FIN TANT QUE
  • AFFICHER, DEMANDER
  • INCREMENTER, DECREMENTER
04 · Exemple

Une luciole pas trop proche

TANT QUE "la luciole est assez loin" est FAUX FAIRE

AFFECTER une position aléatoire à la luciole

SI la différence est assez grande ALORS

AFFECTER VRAI à "la luciole est assez loin"

FIN SI

FIN TANT QUE

05 · Traduction

Du pseudo-code au code JavaScript

while (!estAssezLoin) {

positionLucioleX = Math.floor(Math.random() * 740) + 30;

...

}

Chaque mot-clé correspond à une instruction déjà connue.

06 · Bonnes pratiques

Structurer son code

  • Déclarer les valeurs importantes au début.
  • Garder un seul niveau d'indentation par bloc.
  • Éviter de répéter le même calcul.
07 · Nomenclature

Nommer clairement

  • camelCase pour les variables et les constantes.
  • MAJUSCULES_AVEC_TIRETS_BAS pour les constantes de configuration.
  • Un nom booléen commence par est ou a.
08 · Projet de classe

Trouver une position pour la luciole

La luciole apparaît toujours assez loin du joueur, sans utiliser de tableau.

09 · Travail de classe

Le sentier obscurci

Analyser, rédiger le pseudo-code, puis programmer une réserve de lumière qui diminue à chaque pas.
